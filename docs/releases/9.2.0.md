# EMTG Community Edition 9.2.0

The first Community Edition release builds on NASA's Evolutionary Mission
Trajectory Generator to make mission design more accessible to researchers,
engineers, and developers. It combines open-source solver access, managed
builds, and public Python result interfaces, while retaining NASA authorship,
scientific formats, and license notices.

## What is included

- **IPOPT by default.** The public CLI uses an open-source nonlinear solver.
  Licensed SNOPT remains an optional source-build backend and is excluded from
  public binaries.
- **Simpler builds and portable bundles.** Build scripts provision pinned
  dependencies, run checks, and package runtime definitions and notices.
  Linux OpenBLAS uses runtime CPU dispatch for its host and target dependencies.
- **Python interfaces for your workflow.** `PyEMTG.Results` parses native output
  and inventories scientific artifacts without a viewer or service. Generic
  OuterLoop search and continuation remain available as optional capabilities.
- **Checks tied to actual artifacts.** Receipts identify the source commit/tree,
  executable, archive, toolchain and dependency evidence. Qualification checks
  extracted bundles and retains scientific failure distinctions.
- **A practical community regression foundation.** The native tests use a
  compressed 18.8 MB SPICE fixture with hashes and offline staging, rather than
  requiring the full development kernel inventory.

## Downloads and qualification

Windows x64 is the primary managed CLI release target. The Ubuntu 22.04 x64
bundle is **experimental**. Download a complete bundle, its checksums and
provenance receipt from this release; standalone executables require an explicit
runtime-data location. `SHA256SUMS` lists the reviewed release assets.

The pre-release managed graph passed hosted Windows/Linux builds, packaging and
relocation checks. Windows qualification included eight bounded native IPOPT
cases and all four AEPS cases with their established budgets and physical
acceptance criteria. A matching-tag build rechecks the actual release artifacts
before publishing the official release. Consult [qualification scope](https://github.com/keystoneintelligence/EMTG/blob/v9.2.0/docs/1_Developers/qualification.md)
for the recorded commits and [SUPPORT.md](https://github.com/keystoneintelligence/EMTG/blob/v9.2.0/SUPPORT.md) for support limits.

Bundles include standard Universe and HardwareModels definitions, examples,
small text kernels, and dependency notices. **Supply the BSP kernels appropriate
to your mission.** The source regression fixture only covers the included tests.
See [installation](https://github.com/keystoneintelligence/EMTG/blob/v9.2.0/INSTALLING.md) and [build instructions](https://github.com/keystoneintelligence/EMTG/blob/v9.2.0/BUILDING.md).

## Migration notes

- Explicitly select `NLP_solver_type` in existing options: `0` is SNOPT, `2` is
  IPOPT. Files relying on NASA's omitted SNOPT default now select IPOPT.
- The general feasibility default is `1e-5`. Dedicated IPOPT regressions specify
  `1e-8`; convergence settings and physical acceptance criteria are distinct.
- Fixed-step integration remains the default; adaptive integration is experimental.
- OuterLoop now writes numeric evaluation seeds to `MBH_RNG_seed` and uses
  `seed_MBH` as a Boolean switch for an actual initial guess. Use a fresh campaign
  for the new case-generation/cache context; previous cold-start results are not
  equivalent evaluations.
- Python qualification uses a common **3.12** interpreter. Optional GUI and
  extension workflows have separate dependency and qualification requirements.

## Scope and attribution

IPOPT and SNOPT can converge to different trajectories. This release does not
claim identical optima or qualification of every NASA mission workflow. macOS,
other platforms, licensed SNOPT execution, the historical GUI, and optional
Propulator/PyHardware builds are outside the managed CLI qualification.

Community Edition is Keystone Intelligence's community fork. NASA does not
maintain or endorse it. Credit Jacob Englander and the original EMTG team, and
identify Community Edition when reporting results produced with this variant.
